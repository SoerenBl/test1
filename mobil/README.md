# Mobile Fotos

Hier rein: eine mobile Zusatzversion eines Hintergrundfotos, unter genau demselben Unterpfad wie das Original — z. B. `mobil/hero.jpg` für `hero.jpg`, `mobil/kategorien/mobility/cover.jpg` für `kategorien/mobility/cover.jpg`.

Details und alle Beispiele: siehe "Eigenes Foto nur für die mobile Ansicht" in der `README.md` im Hauptverzeichnis.
